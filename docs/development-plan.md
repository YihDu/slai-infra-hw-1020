# 开发计划与验收边界

依据：`homework-agentic-optimizer.md`，2026-10-22 与课程网页逐字核对一致。

## 目标

交付能在 20 分钟内读取新 workload、调用模型、形成/修改 MIP、调用 HiGHS、
生成 TileLang 实现并检查和评估的独立系统。所有输出保留精确版本、失败和用量。

## 开发顺序

1. **开发 baseline（当前里程碑）**：统一入口、真实模型调用、受约束的 JSON 建模、
   HiGHS one-hot MIP、LP/MPS 导出、TileLang 源码生成、Z3 索引范围检查、
   CPU 分块 GEMM 与独立 float64 reference 比较、第二轮反馈修正、完整输出。
   CPU shadow 是独立诊断程序，不能证明 TileLang/CUDA 实现正确。
2. **编译与验证接入（完成课程 baseline 的前置项）**：确定课程的无 GPU 编译和
   数值执行路径；固定 TileLang/TVM/CUDA 工具链，编译 sm_121a、导出真实 SASS、
   提取实际寄存器/共享内存信息。对这个精确程序执行数值检查。
   现已通过 Linux ARM64 容器完成无 GPU 编译；课程包只有时序模拟器，未提供数值执行器。
3. **真实性能闭环**：原版模拟器处理编译产物，隔离不支持/超时/资源无效结果；
   用有效模拟结果修正成本权重/约束，保存初始与最终实现以及预测偏差。
4. **提交验收**：五个公开案例、未见过的 GEMM 输入、错误配置、超时、检查点恢复、
   日志完整性、离线依赖、秘密扫描、ZIP 根目录与大小限制。

## 建模与 Agent 的实际权限

Agent 选择 tile/stage/thread 的离散域、共享内存预算和解析成本权重，说明约束与目标。
确定性构建器将这些字段转换为一个有唯一选择约束和资源约束的 HiGHS MIP。
不执行模型生成的 Python。预写 kernel 家族公开披露；求解结果实际控制 tile 和流水级。
成本是未经硬件校准的归一化解析代理量，不是 GB10 延迟，也不宣称找到全局最优实现。
候选空间的特征计算不运行候选性能测试；只有选中点做诊断。

## 证据规范

- 模型请求/可见响应、原始 usage、LP/MPS、solver status/incumbent/bound/gap、源码哈希。
- Z3：对固定、整除的 shape/config 证明不加边界 guard 的 tiled 索引仍在界内；
  用非整除维度测试反例，不证明流水线和浮点。
- CPU shadow：FP16 输入输出，FP32 分块累加，对 float64 独立整矩阵 reference，记录种子与误差。
- `result.json` 只有精确 TileLang 实现通过测试才能写 `checked`；当前阶段返回
  `no_valid_result`，分别保留 CPU 诊断、真实编译和模拟状态。
- 单 GEMM 没有多算子融合选择，TVM 图优化本阶段不适用；不得伪造图优化收益。
- 本地文档/提示词显式列入 state，不依赖个人技能、全局指令或历史对话。

## 风险与优先级

精确内核数值执行路径是剩余首要阻塞项。课程方口头说明不需要 GPU，但提供的材料没有
说明怎样在 CPU 上执行生成的 GPU 程序；编译与模拟已接入，
不以 CPU shadow 或手写 SASS 充当课程 baseline。截止时间为 2026-10-23 23:59 UTC+8。
